# Дипломный проект: веб‑инфраструктура в Yandex Cloud

Проект реализует подход Infrastructure as Code для развёртывания веб‑сервиса в Yandex Cloud. Инфраструктура полностью воспроизводима: её можно поднять одной командой `terraform apply`, а ПО настроить через Ansible.

## Стек
- **Terraform** — управление инфраструктурой (ВМ, VPC, Security Groups).
- **Ansible** — автоматизация настройки ПО (Nginx, мониторинг, бэкапы).
- **Debian 11** — ОС на всех узлах.
- **OS Login** — безопасный доступ к ВМ без распространения SSH‑ключей.

## Структура репозитория
- `main.tf`, `variables.tf`, `outputs.tf` — конфигурация Terraform.
- `site.yml`, `inventory.ini`, `roles/` — Ansible‑плейбуки и роли.
- `artifacts/` — артефакты верификации (выводы `yc`, правила Security Groups).
- `.gitignore` — исключения для Git.

## Артефакты для подтверждения работоспособности
В папке `artifacts/` находятся «слепки» состояния стенда на дату сбора данных — они доказывают, что инфраструктура реально существовала в Yandex Cloud:
- `yc_instances.txt` — список ВМ и их статусы (`RUNNING`).
- `yc_instance_web1.json` — детальные параметры веб‑сервера (зона, публичный IP, платформа).
- `security_group_diplom.json` — правила сетевого доступа (подтверждение сегментации и безопасности).

Эти артефакты получены CLI‑утилитой `yc` и не содержат чувствительных данных.
